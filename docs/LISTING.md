## Per site

Tag and length limits below are as of late 2026 from memory, not checked against each form:
trust the form if it says otherwise.

### Disboard (disboard.org)

- Dashboard → **Add new server** → Lorenzo's Server; this invites the DISBOARD bot (leave its
  permissions alone).
- Fields: description (the long one; Disboard shows its first lines as the summary, so the
  short text people see there is the long description's first paragraph), **tags: up
  to 5** (`gaming`, `co-op`, `chill`, `risk of rain 2`, `minecraft`), language English, category
  Gaming, NSFW off, invite generated by the bot.
- Bump with `/bump` in 🤖・bot-commands every 2 hours. Front Desk pings @Bumper when it's ready.

### top.gg (top.gg/servers)

- top.gg → Add → **Server**, pick Lorenzo's Server; you may need to add the top.gg bot to read
  member counts.
- Fields: short description (the 115-character one), long description (markdown OK), **tags:
  up to 5** from top.gg's own list (Gaming, Community, Social, plus game tags if offered),
  invite link <https://discord.gg/C25hy9Ca9W>, website <https://discord.lscaturchio.xyz/>,
  banner (`banner.png`).
- Ranking is vote-based: ask members to vote every 12 hours.

### Discadia (discadia.com)

- Sign in → **Add server**; Discadia's bot reads the member count.
- Fields: short description, long description, category Gaming, **tags: up to 10** (use all ten
  above), language English, invite link, NSFW off.
- `/bump` with the Discadia bot every 12 hours (add it to 🤖・bot-commands).

### Discord Server Discovery (in the app)

Not open to us yet. Requirements, as of late 2026 (check Server Settings → **Enable Discovery**,
which shows a live checklist):

- **Community** turned on (done by `polish_server.py`).
- **At least 1,000 members.**
- **At least 8 weeks old.**
- **Activity**: enough members chatting and online over the last few weeks; Discord doesn't publish
  exact thresholds.
- **2FA required for moderators** (Server Settings → Safety Setup).
- **Clean safety record**: no recent Trust & Safety strikes; server name, description and channel
  names free of slurs and NSFW words. AutoMod and the verification level count in your favour.
- **Not age-restricted**: servers or channels flagged age-restricted / NSFW can't be in Discovery.
  Our 18+ is a rule, not the NSFW flag; keep it that way.
- Discovery listing: description (the short one), **primary category** Gaming, **up to 5 tags**
  (`gaming`, `co-op`, `chill`, `risk of rain 2`, `minecraft`; Discovery tags are searchable keywords, so
  no age tag), banner/cover image (`hero.png`), primary language English.
